# Project 03 — Pricing Plans

A responsive SaaS pricing page made with semantic HTML, CSS Grid, and vanilla JavaScript. This beginner project practices responsive card layouts, accessible billing controls, transitions, and CSS reduced-motion preferences.

## Plans and sample pricing

- Starter: $0 monthly or yearly.
- Pro: $15 monthly or $144 yearly (20% lower than 12 monthly payments).
- Team: $30 monthly or $288 yearly (20% lower than 12 monthly payments).

The made-up prices live in each `.price` element's `data-monthly` and `data-yearly` attributes. The toggle updates the displayed prices, billing labels, and accessible state. Add `?billing=yearly` to the page URL to open directly in the yearly view. Plan buttons show a short confirmation with the selected plan and billing period.

## Run locally

Open `index.html` in a browser or use VS Code Live Server. No dependencies or build step are required.

## Publish and capture the required views

Publish the static files with GitHub Pages or another static host. For the submission screenshots, capture the full pricing section once with **Monthly** selected and again with **Yearly** selected.
